# Digital Image Processing Assignments

Coursework repository for digital image processing assignments and project
artifacts. The repository contains notebooks, images, reports, generated
submissions, and project outputs.

## Repository Layout

- `Assignment1/` contains image-processing notebooks and input images captured
  under different lighting conditions.
- `Assignment2/` contains a filtering assignment, notebook, generated image,
  assignment brief, and local README with dataset notes.
- `Assignment3/` contains degradation and restoration material, notebooks,
  images, generated submission data, and report.
- `Project/` contains the project brief, report, notebook, watermarked images,
  and generated submission data.

## Requirements

Use a Python environment with Jupyter Notebook support. Typical image processing
dependencies may include NumPy, OpenCV, Pillow, matplotlib, and related
scientific Python packages depending on the notebook.

## Usage

Open the notebook in the assignment or project directory you want to inspect.
Input images and generated outputs are stored beside the notebook that uses
them. Read the corresponding PDF brief and report for task definitions,
methodology, and results.

## Notes

The repository is organized by assignment so that each directory can be reviewed
independently.
